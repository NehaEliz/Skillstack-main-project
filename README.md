# SkillStack

SkillStack is an AI-driven platform to track, categorize, and visualize your learning skills. It helps users manage learning resources, monitor progress, and receive personalized recommendations.

---

## 🚀 Setup Steps

### **Backend**
1. Navigate to the backend folder:
   cd skillstack
   cd backend

2. Install required Python dependencies:

    pip install -r requirements.txt


3. Start the backend server:

    python app.py

    The backend will run at: http://127.0.0.1:5000


Frontend

1. Navigate to the frontend folder:
    cd skillstack
    cd frontend

2. Install Node.js dependencies:

    npm install

3. Start the React development server:

    npm start

    The frontend will run at: http://localhost:3000



🌟 Features

Add & Track Skills – Add learning resources and track progress over time.

Progress Visualization – Charts and graphs to visualize skill growth.

Personalized Recommendations – Suggest resources based on skill gaps.

Responsive Dashboard – User-friendly interface accessible on desktop and mobile.

Backend Integration – Flask API handling data storage and retrieval.

Data Persistence – SQLite database to store user data and resources.





🧰 Tech Stack

Frontend: React, Recharts, Axios

Backend: Python, Flask

Database: SQLite



🎬 Demo Instructions

To quickly see the project in action:

Start the backend server (python app.py)
